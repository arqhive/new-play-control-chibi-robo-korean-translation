Wii로 즐기는 치비로보! 한글 패치 v0.9 (Wii)
==========================================

일본판 「Wiiであそぶ ちびロボ！」(Wiiであそぶセレクション, 북미판 New Play Control! Chibi-Robo!)
이미지에 적용하는 한글 패치입니다.
게임 데이터는 들어 있지 않으며, 직접 소유한 디스크에서 만든 이미지가 필요합니다.


[사용법]

  1. 이 폴더에 원본 이미지를 넣고 「패치하기.bat」을 더블클릭합니다.
     또는 원본 이미지 파일을 「패치하기.bat」 위에 끌어다 놓습니다.
  2. 끝나면 원본과 같은 폴더에 「Chibi-Robo! (Korean) [R24J01].iso」가 생깁니다.
     원본이 WBFS이면 결과도 WBFS로 만들어집니다. 원본 파일은 그대로 남습니다.

  처음 실행할 때 Windows가 경고하면 「추가 정보 → 실행」을 누르세요.
  Windows 10 이상에 기본으로 들어 있는 PowerShell을 사용합니다.
  작업 중에 약 10GB의 빈 공간이 필요합니다(작업용 파일 포함).

  결과 형식이나 이름을 바꾸려면 명령줄에서 두 번째 인자로 지정합니다.
    패치하기.bat "원본.wbfs" "D:\wbfs\치비로보 한글.iso"


[원본 이미지]

  게임: Wiiであそぶ ちびロボ！ 일본판 (게임 ID R24J01)

  패처가 게임 파일 하나하나를 원본과 비교하므로,
  덤프 방식에 따라 이미지 전체 MD5가 달라도 게임 파일만 같으면 적용됩니다.

  지원 형식          결과
  ---------------    ------
  ISO                ISO
  WBFS               WBFS
  CISO, WIA, WDF     ISO
  RVZ                지원 안 함 → Dolphin에서 ISO로 변환한 뒤 적용
                     (게임 우클릭 → 변환 → ISO)
  NKit               지원 안 함 → NKit 도구로 원래 ISO로 되돌린 뒤 적용

  이미 한글 패치를 적용한 이미지에는 적용되지 않습니다. 항상 일본판 원본에 적용하세요.
  게임큐브판 「ちびロボ！」(GGTJ01)용 패치는 따로 있습니다.


[오류 메시지]

  ~가 아닙니다. 읽은 게임 ID          다른 게임입니다.
  원본 게임 파일이 다릅니다           이미 패치한 이미지이거나 손상된 덤프입니다.
  wit.exe 실행 실패                   RVZ·NKit 등 지원하지 않는 형식이거나 손상된 이미지입니다.
                                      위 [원본 이미지] 표를 참고해 ISO로 바꾸세요.


[실행]

  - Wii U의 vWii(USB Loader GX)에서 확인했습니다.
